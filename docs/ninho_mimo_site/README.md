# Ninho & Mimo — Site institucional e vitrine

Landing page responsiva da marca **Ninho & Mimo**, criada em HTML, CSS e JavaScript puro.

## Como abrir

Abra o arquivo `index.html` no navegador.

Para executar com um servidor local:

```bash
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Recursos incluídos

- Layout premium e responsivo
- Navegação mobile
- Filtros de categorias e produtos
- Favoritos com contador
- Busca em modal
- Formulário de newsletter demonstrativo
- Animações ao rolar
- Seções de curadoria, conteúdo e guia por idade
- Logo da marca incorporado
